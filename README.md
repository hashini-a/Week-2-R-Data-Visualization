# Week 2 - Data Visualization and Insight Communication using R

This project is part of my Week 2 internship task on **Data Visualization and Insight Communication using R**.

## Objective

The objective is to analyze a public dataset and communicate important patterns, trends, and insights using different visualizations created in R.

## Dataset

The project uses the **AirPassengers** dataset, which contains monthly airline passenger data from **1949 to 1960**.

## Visualizations

The following charts were created using R and ggplot2:

* Line Chart
* Bar Chart
* Histogram
* Scatter Plot
* Box Plot

These visualizations help identify trends, seasonal patterns, distributions, and relationships in the dataset.

## Tools Used

* R
* ggplot2
* Microsoft Word
* GitHub
